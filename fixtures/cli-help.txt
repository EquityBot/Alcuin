Alcuin CLI v0.1.0: Consult Latest (GPT-6), with Pro first and verified Extra High fallback.

Usage: alcuin [options] [command] [prompt]

Latest (GPT-6) consultation tool. Pro is first; verified Pro unavailability
permits Extra High on GPT-6.

Arguments:
  prompt                                Prompt text (shorthand for --prompt).

Options:
  -V, --version                         output the version number
  -p, --prompt <text>                   User prompt to send to the model.

                                        conversation or an OpenAI/Azure
                                        Responses API run.
  --followup-model <model>              For multi-model API sessions, choose
                                        which model response to continue from.

                                        exclude). Oversized files are rejected

  bridge                                Bridge a Windows-hosted ChatGPT session
                                        to Linux clients.
  tui                                   Launch the interactive terminal UI for
                                        humans (no automation).

                                        and routing.
  docs                                  Documentation maintenance utilities.

Tips
• Pass a prompt and attach relevant source with --file …; Alcuin cannot inspect your project directly.
• Preview the bundle with --dry-run summary --files-report and keep total input under ~196k tokens.
• Explain the decision, constraints and prior attempts in a short project briefing.
• Fresh browser requests verify Latest/GPT-6 and Pro before submission. A positively unavailable owned Pro control permits verified Extra High on GPT-6. Missing or ambiguous controls stop the run. New older-model dispatch is refused; saved results remain readable without replay. UI labels do not attest backend identity.
• --perf-trace records browser queue, setup, mode selection, upload, generation and capture durations.
• Spell out the project + platform + version requirements (repo name, target OS/toolchain versions, API dependencies) so Alcuin doesn’t guess defaults.
• When comparing multiple repos/files, spell out each repo + path + role (e.g., “Project A SettingsView → apps/project-a/Sources/SettingsView.swift; Project B SettingsView → ../project-b/mac/...”) so the model knows exactly which file is which.
• Best results: 6–30 sentences plus key source files; very short prompts often yield generic answers.
• Alcuin is one-shot by default. Continue saved API or ChatGPT browser sessions with --followup <sessionId|responseId>; use repeated --browser-follow-up for planned same-run ChatGPT turns.
• Run --files-report to inspect token spend before hitting the API.
• Non-preview Pro runs spawn detached sessions. If the CLI times out, do not re-run — reattach with alcuin session <slug> to resume/inspect the existing run.
• Set a memorable 3–5 word slug via --slug "<words>" to keep session IDs tidy.
• Finished sessions auto-hide preamble logs when reattached; raw timestamps remain in the saved log file.
• Need hidden flags? Run alcuin --help --verbose to list search/token/browser overrides.
• If any Alcuin session is already running, do not start new API runs. Attach to the existing browser session instead; only trigger API calls when you explicitly mean to.
• Duplicate prompt guard: if the same prompt is already running, new runs are blocked unless you pass --force—prefer reattaching instead of spawning duplicates.

Examples
  alcuin --render --copy --prompt "Review the TS data layer for schema drift" --file "src/**/*.ts,*/*.test.ts"
    Build the bundle, print it, and copy it for manual paste into ChatGPT.

  alcuin --engine browser --model gpt-6-pro --browser-thinking-time pro --prompt "Cross-check the data layer assumptions" --file "src/**/*.ts"
    Consult GPT-6 with independently verified Pro effort.

  alcuin perf-summary run-a.json run-b.json --json
    Summarise numeric phase totals from selected consultation traces.

  alcuin recover-native --request request.json --write-output answer.md
    Save a completed native ChatGPT reply while Alcuin's manual-login Chrome is open.

  alcuin status --hours 72 --limit 50
    Show sessions from the last 72h (capped at 50 entries).

  alcuin session <sessionId>
    Attach to a running/completed session and stream the saved transcript.

  alcuin --prompt "Ship review" --slug "release-readiness-audit"
    Encourage the model to hand you a 3–5 word slug and pass it along with --slug.

  alcuin --prompt "Tabs frozen: compare Project A SettingsView (apps/project-a/Sources/SettingsView.swift) vs Project B SettingsView (../project-b/mac/App/Presentation/Views/SettingsView.swift)" --file apps/project-a/Sources/SettingsView.swift --file ../project-b/mac/App/Presentation/Views/SettingsView.swift
    Spell out what each attached file is (repo + path + role) before asking for comparisons so the model knows exactly what it is reading.


Examples:
  # Quick API run with two files
  alcuin --prompt "Summarize the risk register" --file docs/risk-register.md docs/risk-matrix.md

  # Browser run (no API key) + globbed TypeScript sources, excluding tests
  alcuin --engine browser --prompt "Review the TS data layer" \
    --file "src/**/*.ts" --file "!src/**/*.test.ts"

  # Build, print, and copy a markdown bundle (semi-manual)
  alcuin --render --copy -p "Review the TS data layer" --file "src/**/*.ts" --file "!src/**/*.test.ts"
